# Community formulas

These 129 formulas come from the Mandelbulb3D 1.99.37 package that Machina
Infinitum offers as a free download on their public website. They are not in
the official MB3D repository (github.com/thargor6/mb3d), whose formulas the
program ships as well. People of the Fractal Forums and DeviantArt
communities wrote them and shared them freely for use in Mandelbulb3D; each
file's description (after `[END]`) says more. All credit goes to their
authors, named below as each file names them. If you wrote one of these and
do not want it here, open an issue and it is taken out.

`teapot.m3f` (DarkBeam, 2016) is under the Creative Commons
Attribution-ShareAlike 3.0 licence, as its file says.

Left out of the package's formulas: `JIT_gnj_RealPower_m02_01`,
`JITMANDELBULB` and `JITMyNewFormula` (their files are cut off: the code ends
in `en` instead of `end`, so they compile neither here nor in MB3D) and
`JITtest` (a test that sets the coordinates to constants).
